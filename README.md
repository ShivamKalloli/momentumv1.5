# Momentum AI Co-Pilot 🎯

An intelligent goal-setting and task management app powered by AI that helps users break down complex goals into actionable daily tasks.

## 🌟 Features

### 🤖 AI-Powered Goal Planning
- **Smart Goal Analysis**: AI determines if your input is a simple task or complex goal
- **Intelligent Questionnaires**: Dynamic questions based on your specific goal
- **Personalized Plans**: Custom daily plans tailored to your experience and time availability
- **Knowledge Gap Analysis**: AI identifies what you need to learn and recommends resources

### 📱 Beautiful Mobile Experience
- **Clean, Modern UI**: Apple-level design aesthetics with smooth animations
- **Tab-Based Navigation**: Easy access to Today, Goals, and Profile
- **Real-time Progress Tracking**: Visual progress bars and completion statistics
- **Responsive Design**: Works perfectly on all screen sizes

### 🎯 Goal Management
- **Complex Goal Breakdown**: 30-90 day goals broken into daily actionable tasks
- **Simple Task Creation**: Quick addition of one-off tasks
- **Goal Status Management**: Pause, resume, complete, or delete goals
- **Progress Visualization**: Track completion rates and time invested

### 📅 Daily Task Management
- **Today's Focus**: Clean view of today's tasks with time estimates
- **Task Completion**: Simple tap to mark tasks complete
- **Progress Overview**: See daily completion rates and total time planned
- **Smart Scheduling**: Tasks automatically scheduled based on your goal timeline

### 🔐 Secure Authentication
- **Supabase Auth**: Secure email/password authentication
- **Data Privacy**: All user data is private and secure
- **Cross-Device Sync**: Access your goals from any device

## 🚀 Technology Stack

- **Frontend**: React Native with Expo Router
- **Backend**: Supabase (Database, Auth, Edge Functions)
- **AI**: Google Gemini AI for intelligent plan generation
- **Styling**: Custom StyleSheet with modern design principles
- **Icons**: Lucide React Native for consistent iconography

## 🎨 Design Philosophy

Momentum follows Apple's design principles:
- **Clarity**: Clean, readable interfaces with proper typography
- **Deference**: Content-first design that gets out of the way
- **Depth**: Subtle animations and visual hierarchy guide users

## 🧠 AI Intelligence

The app uses advanced AI to:
1. **Analyze Goal Complexity**: Distinguish between simple tasks and complex goals
2. **Generate Smart Questions**: Ask relevant questions based on goal type
3. **Create Personalized Plans**: Build day-by-day plans considering user experience and time
4. **Provide Insights**: Offer motivational insights and resource recommendations
5. **Fallback Gracefully**: Intelligent fallbacks when AI is unavailable
